# Figma handoff notes

1. Create a new Figma Design file named **VitalSync – Sprint 13 Wireframes**.
2. Import the three SVG files from this folder (drag each SVG onto the Figma canvas).
3. Keep the imported desktop frames as low-fidelity wireframes; do not present them as final UI.
4. Create mobile frames for each screen (suggested viewport: 390 × 844) and rearrange the content vertically.
5. Add a Doctor and Patient dashboard variant where the visible navigation/actions differ.
6. Publish the Figma file with view access and paste its URL into the Figma file field in `README.md`.

The SVGs are editable after import. The public Figma URL must be created from your own Figma account; it cannot be generated by this local project pack.
